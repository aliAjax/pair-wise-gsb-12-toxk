# 危化品装卸接地与泄漏应急联动台

- 行业：危化品仓储物流
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在车辆调度小工具基础上扩展的装卸安全联动台，数据保存在浏览器 localStorage（key：`hazchem-dock-console-v1`），刷新后任务、接地记录、装车版本与泄漏事件保持一致。

## 代码分层

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 领域模型：派车单、接地检查、装车版本、泄漏事件 |
| `src/data.ts` | 车辆资料：罐车、司机（危化证）、装卸位、介质目录 |
| `src/rules.ts` | 判定规则（纯函数）：放行校验、接地监测、泄漏封锁、时段冲突 |
| `src/store.ts` | Pinia 状态与流转：登记/放行、装车/中止/复装、泄漏联动与持久化 |
| `src/components/*` | 页面：登记表单、任务看板与卡片、泄漏面板、资料目录 |

## 业务规则

1. **派车单登记**：罐车、司机、装卸位、介质、计划时段、计划量与接地实测值一次登记。
2. **整单不放行**（输入原样保留，可修改后重新校验，每次检查留痕）：
   - 接地电阻 > 10Ω；
   - 接地夹未回讯；
   - 司机危化品从业资格证已过期；
   - 另校验罐车/装卸位介质资质、额定载重、时段冲突。
3. **装车中接地断开**：记录已装量时若电阻超限或接地夹脱离，立即中止当前装车版本，封存已装量与中止原因；接地恢复后可"复装"，自动生成 v2、v3…… 版本，已装量累计。
4. **泄漏联动**：登记泄漏事件后同装卸位立即封锁，正在装车的任务联动急停并标记"泄漏联动"；事件关闭前该装卸位不得接新任务、不得复装。
