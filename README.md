# 危化品装卸接地与泄漏应急联动台

由「车辆调度小工具」扩展而来，面向危化品罐车装卸环节的接地联锁与泄漏应急联动。

- 行业：危化品物流
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

1. **派车登记**：登记罐车、司机、装卸位、充装介质、计划量与作业时段，并录入放行前接地读数。
2. **整单不放行**：接地电阻 > 10Ω、接地夹未回讯、司机危化证过期、介质与罐车核定不符 / 超核载、时段或装卸位不满足要求时，整单不予放行，且**表单输入原样保留**。
3. **泄漏锁定**：装卸位存在未关闭的泄漏事件时，该位不得接新任务（派车选项禁用并列入拦截原因）。
4. **装车中止**：装车过程中接地断开（电阻超限或夹钳失去回讯）立即中止，记录中止时的**装车版本、已装量、原因、时间**；接地恢复安全后才可复装，复装生成新版本，历史中止记录保留不变。
5. **泄漏联动**：上报泄漏事件时立即联锁中止同装卸位正在进行的装车；事件关闭后装卸位解锁。
6. **刷新一致**：任务、接地读数、泄漏事件、装车版本统一持久化到 localStorage，刷新后状态一致（装车模拟可用「继续装车模拟」恢复）。

## 目录分层

- `src/data/`：车辆资料层 —— 司机、罐车、装卸位、介质台账与演示种子数据
- `src/rules/`：判定规则层 —— 接地判定、派车放行闸门、泄漏锁定等纯函数
- `src/pages/`：页面层 —— 派车登记、装车/接地监控、泄漏应急联动
- `src/components/`：可复用组件（任务卡、接地监控、状态徽标）
- `src/stores/`：Pinia 状态层，统一持久化任务、接地、事件与版本
- `src/types.ts`：领域类型
